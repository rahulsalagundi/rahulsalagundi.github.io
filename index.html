open source deployment/instadeploy

            
InstaDeploy

            
Deploy Docker. Get a URL.

            
A self-hosted PaaS. Run any Docker app on your own machine and get a public HTTPS URL in seconds, with no port forwarding, reverse proxy, certificates or cloud bill.

            
    
              
  • Pull-based control plane. The server records desired state; per-host Go agents long-poll a task queue and run the containers.
    • 
              
  • Zero open ports. Outbound tunnels to an edge gateway that terminates TLS, so it works behind NAT and firewalls.
    • 
              
  • Continuous deployment on every git push, with revisions, one-click rollback, health checks and live logs.
    • 
              
  • Secure by default. Encrypted secrets redacted from logs, revocable host tokens, and checks that block privileged containers.
    •
